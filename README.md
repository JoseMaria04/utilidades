# utilidades — Fabric 1.20.1

Recetas extra para Minecraft **1.20.1 (Fabric)** para cosas que en vanilla no se pueden fabricar. Mod sin código: solo datos.
Originalmente hecho con MCreator para Forge 1.12.2.

| Receta | Resultado |
|---|---|
| 3 cuero + 2 cuerdas + 2 lingotes de hierro | Montura |
| 8 bloques de oro + manzana | Manzana de Notch (encantada) |
| 6 cuero / hierro / oro / diamantes + 1 lana | Armadura de caballo del material |

Requiere Fabric Loader y Fabric API. Licencia MIT.

*Extra recipes for Fabric 1.20.1: saddle, enchanted golden apple and horse armours. Data-only mod, needs Fabric API.*

Compilar: `./build.sh`.
